# Archive

Earlier versions of Java4U, kept for reference. They are no longer developed; the current
launcher is in [`../java4u-go`](../java4u-go).

- [`csharp-desktop/`](csharp-desktop): the first Windows-only WPF app (.NET), with the original
  Chunky alpha and the browser layout preview.
- [`rust/`](rust): the Rust launcher (core library, CLI and egui desktop app). Java4U's Go
  version is a rewrite of this one and reads the same data files.
